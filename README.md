# 🛒 ТехноДүкен (Django + Bootstrap)

Бұл веб-қосымша — техникалық өнімдерді онлайн түрде көру, тапсырыс беру және төлем жасау жүйесін көрсететін Django жобасы.

---

## 🔧 Құрамында:

- 🧑‍💻 **Аутентификация** (тіркелу, кіру, шығу)
- 📦 **Өнімдер тізімі** (категориялар мен брендтер)
- 💳 **Checkout жүйесі** (full/credit/installment төлем)
- 🛒 **Менің тапсырыстарым** (detail және болдырмау)
- 🧠 **Админ панель + Мониторинг** (әрекет логтары)
- 🎨 **Bootstrap арқылы интерфейс** (light mode)

---

## 📂 Қолданылатын технологиялар:

- Python 3.x
- Django 4/5
- PostgreSQL немесе SQLite
- Bootstrap 5 (CDN)

---

```bash
git clone https://github.com/сенің_логинің/technoshop.git
